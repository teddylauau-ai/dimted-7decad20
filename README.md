# Lumo

Yeah — you're describing DIMTED as a social game, where the chat itself is part of the progression system. Instead of adding random games like chess, make the whole app feel like a game that evolves as you use it.

Use this as the main upgrade prompt in Lovable:

Completely rethink DIMTED's progression and social systems.

DIMTED should NOT just be a Discord-style chat app with some games added.

The core idea is:

CHAT → XP → LEVEL UP → UNLOCK → EXPLORE → PLAY → PROGRESS → CUSTOMISE → SOCIALISE

The more someone uses DIMTED, chats with friends, joins communities, participates in activities, and plays DIMTED's unique games, the more the platform evolves for them.

Make DIMTED feel like a futuristic social game disguised as a communication platform.

DIMTED WORLD

Create a central progression system called the DIMTED WORLD.

Every user has a profile level and progression path.

Users earn XP naturally through meaningful activity:

Sending messages

Having conversations

Joining communities

Making friends

Participating in community events

Creating content

Playing DIMTED activities

Completing challenges

Helping other users

Discovering new parts of DIMTED

Do NOT reward spam.

Implement sensible XP cooldowns and activity rules so users cannot simply send thousands of useless messages to exploit progression.

LEVEL SYSTEM

Create levels from 1 onward.

Example progression:

Level 1 — Newcomer
Level 2 — Explorer
Level 3 — Regular
Level 5 — Connected
Level 10 — Veteran
Level 15 — Elite
Level 25 — Legend
Level 50 — Mythic

Make higher levels increasingly difficult to reach.

Every few levels unlock something genuinely interesting.

Examples:

Level 2

Profile customisation

Custom status effects

Profile banner

Level 7

Animated profile decorations

Level 10

Personal profile theme

Level 12

Special chat effects

Custom profile entrance animation

Level 20

Level 25

Rare profile cosmetics

Level 30

Advanced community customisation

Level 40

Legendary cosmetics

Level 50

Mythic profile status

Make unlocks visual, social, and functional rather than simply giving users numbers.

XP SHOULD FEEL ALIVE

Create an animated XP system.

When someone levels up:

LEVEL UP!

The screen should briefly animate with:

XP particles

Progress bar animation

New unlock notification

Sound-ready animation architecture

New badge

Unlock preview

Show:

LEVEL 17
██████████████░░░░
2,430 / 3,000 XP

Make progression satisfying without becoming annoying.

DIMTED ENERGY

Introduce a second system called ENERGY.

Energy represents a user's activity and momentum within DIMTED.

Energy can increase through:

Conversations

Community participation

Playing activities

Completing challenges

Energy can unlock temporary or cosmetic effects.

For example:

"ENERGY SURGE"
Double XP for the next 30 minutes.

Do not make this pay-to-win.

THE DIMTED GAME

Create a unique game built directly into the platform.

Do NOT use generic games like Chess, Tic-Tac-Toe, Snake, etc.

The game should be connected to the user's social activity.

Concept:

THE DIMTED REALM

Every user has a small futuristic digital space that develops as they progress.

At Level 1, the space is almost empty.

As the user levels up, they unlock:

Buildings

The user's DIMTED profile becomes their own little digital world.

Users can:

Leave messages

Complete challenges

Play social activities

Collect items

Unlock areas together

This makes chatting and socialising directly connected to the game.

MOST IMPORTANT DESIGN PRINCIPLE

DIMTED should make users think:

"I joined to chat, but now I want to see what I can unlock."

The progression should happen naturally through social interaction.

Do NOT turn DIMTED into a grind.

The goal is for chatting, friendships, communities and activities to naturally feed into one connected progression system.

DIMTED should feel like a living digital world that grows with the user.

Make the whole experience feel cohesive, futuristic, social, mysterious, rewarding and genuinely fun.
